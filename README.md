# Cloud 101 — In-Store Menu

A browse-only menu website for **Cloud 101 Smoke & Vape Shop** (4327-1 University Blvd S, Jacksonville, FL). It mirrors the look, copy and full product catalog of cloud101smokeandvape.com, with **no delivery, cart, checkout or payments** — customers browse here and buy in-store.

## Pages
- **Home** (`#/`): hero, featured categories, today's deals, featured brands, how it works, why Cloud 101, reviews, FAQ.
- **Menu** (`#/menu`, `#/menu/<category>`, `#/menu/<category>/<sub>`): every product with brand, size, price, sale price and description. Includes search, a brand filter, sorting, a deals-only toggle, and a grid or "menu board" layout. Tap any item for its details and all flavor options.
- **About** (`#/about`) and **Visit Us** (`#/visit`): hours with live open/closed status, map, and contact details.

## Running it
It's a static site with no build step. Open `index.html` directly, or serve the folder:

```sh
python3 -m http.server 8000
```

It can be hosted on any static host (GitHub Pages, Netlify, Cloudflare Pages, etc.).

## Menu data
`js/menu-data.js` holds all 1,780 catalog listings (1,545 unique products after cross-listed items are merged), grouped into 1,198 menu cards where flavors share a name and price. It is generated by `tools/build_menu_data.py` from a snapshot of the live site's category pages. Category intros and the per-category description templates live at the top of that script.

Product photos (1,368 files) are stored in `assets/products/` as 600px WebP files, so the site doesn't depend on any outside image host. Each file is named after the first 12 characters of the SHA-1 of its original Saucey URL, and the builder uses a local file whenever one exists. Items without a photo show a Cloud 101 placeholder.
